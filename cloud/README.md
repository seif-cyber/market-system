# موقع متابعة المبيعات (Firebase)

الموقع بيخلّي **صاحب المحل** يتابع مبيعاته وأرباحه من الموبايل، ويتثبّت زي تطبيق (PWA).
برنامج الكاشير بيشتغل أوفلاين دايمًا، ولما يلاقي نت بيبعت ملخص كل 15 دقيقة.

## إزاي المالك بيتربط بمحله
1. **على جهاز المحل:** المالك يدخل برنامج الكاشير ← الإعدادات ← «ربط حساب المالك بالموبايل». بيظهر **كود** (صالح 15 دقيقة) و QR.
2. **على موبايل المالك:** يفتح الموقع ويسجّل دخول بنفسه (بجوجل أو بإيميل)، ويكتب الكود أو يمسح الـ QR.
3. خلاص. المحل اتربط بحسابه، وبيشوف بياناته. **مفيش باسورد بيتكتب على جهاز المحل خالص.**

- المالك بس (دور «مالك» في برنامج الكاشير) هو اللي يقدر يعمل الكود، والمدير والكاشير لأ.
- المحل مربوط بحساب مالك **واحد** بس. لو عايز تغيّره: فك الربط من برنامج الكاشير أو من قايمة الموقع، وبعدين اربط بكود جديد.
- لو المالك عنده أكتر من محل، بيربطهم كلهم بنفس الحساب ويبدّل بينهم من القايمة.

## إعداد Firebase (مرة واحدة)
مشروعنا: `sales-system-74300`.

1. **Authentication ← Sign-in method:** فعّل التلاتة:
   - **Google** (هيطلب إيميل الدعم، اختار إيميلك).
   - **Email/Password** (للدخول بالإيميل وإنشاء حساب).
   - **Anonymous** (هوية جهاز المحل نفسه، من غير أي باسورد).
2. **Firestore Database:** تم إنشاؤه (Production mode).
3. **بيانات الويب:** Project settings ← General ← Your apps ← أضف تطبيق Web (`</>`) وانسخ `apiKey` و `appId` في `apps/cloud/public/firebase-config.json` (`projectId` و `authDomain` متظبطين). القيم دي مش أسرار.
4. **الرفع** (من جهازك، من فولدر المشروع):
   ```
   npm install -g firebase-tools
   firebase login
   npm install
   npm run build:cloud
   firebase deploy --only hosting,firestore --project sales-system-74300
   ```
   الموقع هيبقى على `https://sales-system-74300.web.app`.
5. **برنامج الكاشير:** نفس ملف `firebase-config.json` بيتحط جوه البرنامج وقت البناء، فاعمل commit للملف وابني الـ exe تاني.

## الأمان
- **القواعد** (`cloud/firestore.rules`): جهاز المحل بس هو اللي يكتب في بياناته؛ المالك المربوط بس هو اللي يقرا؛ لا حد غيره. كود الربط مؤقت (15 دقيقة) ولمحل واحد، ومحل ملوش غير مالك واحد، ومفيش حد يقدر يغيّر المالك من غير فك الربط.
- **اختبار القواعد** على محاكي Firestore (محتاج Java):
  ```
  cd cloud/rules-test
  npm install
  npm test
  ```
- لو حسابك اتسرّب أو موبايل اتسرق: غيّر باسورد الحساب (أو شيل الجهاز من جوجل)، وفك الربط من برنامج الكاشير.

## لو حصلت مشكلة
| الرسالة | الحل |
|---|---|
| «فعّل Anonymous في Firebase Authentication» | فعّل Anonymous من Sign-in method |
| «الصلاحيات في Firebase مش مظبوطة» | انشر القواعد: `firebase deploy --only firestore` |
| «الدومين ده مش مضاف» | Authentication ← Settings ← Authorized domains |
| «الكود غلط أو انتهى» | اطلب كود جديد من برنامج الكاشير (صالح 15 دقيقة) |
| «المحل ده مربوط بحساب تاني» | فك الربط من برنامج الكاشير الأول |
