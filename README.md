# نظام كاشير للسوبر ماركت

برنامج كاشير يشتغل أوفلاين على ويندوز، ومعاه موقع متابعة للمالك على الموبايل.

## المميزات
- **الكاشير:** قارئ الباركود، وباركود الميزان (وزن/سعر)، وبيع نقدي/فيزا/آجل، وتعليق الفاتورة، والمرتجعات، وطباعة الإيصال على طابعة حرارية.
- **الورديات:** تسليم الدرج بين الكاشيرية (المبلغ المتسلّم مقفول والتغيير باعتماد المدير)، وتقرير الإقفال والفروق.
- **الخزنة:** رصيد كاش وبنك، وكل حركة مالية في دفتر واحد لا يتعدّل، وفحص مطابقة تلقائي.
- **المخزون:** تنبيه النواقص والصلاحية، وجرد، واستيراد من Excel (CSV).
- **العملاء والآجل، المصاريف، لوحة تحليلات** (ربح، ساعات الذروة، أداء الكاشيرية).
- **ترخيص بمفتاح** مربوط بالجهاز، ونسخ احتياطي واستعادة، ووضع تجريبي ببيانات وهمية.
- **موقع متابعة للموبايل** (PWA) على Firebase، بيتثبّت زي تطبيق.

## التشغيل والتطوير
```
npm install
npm test            # الاختبارات
npm run typecheck
npm run build -w @market/ui && npm run start -w @market/desktop   # تشغيل البرنامج (محتاج keys/public.pem)
npm run build:cloud # موقع المتابعة
```
- بناء ملف التثبيت `.exe` بيتم على GitHub Actions (ملف `.github/workflows/build-windows.yml`)، وبتلاقيه في Artifacts.
- مفاتيح التفعيل: `node` + `tools/license.ts` (المفتاح الخاص يفضل عندك ومايترفعش).
- رفع موقع المتابعة على Firebase: [`cloud/README.md`](cloud/README.md).

## هيكل المشروع
| المسار | المحتوى |
|---|---|
| `apps/desktop` | برنامج Electron (الخدمات، الطباعة، الترخيص، المزامنة) |
| `apps/ui` | شاشات البرنامج (React، عربي RTL) |
| `apps/cloud` | موقع المتابعة (PWA + Firebase) |
| `packages/db` | قاعدة بيانات SQLite والمنطق المالي |
| `packages/core` | منطق مشترك (حسابات، ترخيص، عروض) |
| `tools` | أدوات المطوّر (توليد المفاتيح والأيقونات) |
